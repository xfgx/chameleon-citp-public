# CITP Stream Migration & Resumable Sessions

## 1. Уровни поддержки миграции (Migration Maturity Levels)

CITP формально определяет 4 уровня мобильности и миграции сетевых сессий:

### Level 1 — Same-Node Reconnect (Поддерживается / Production-Ready)
- При разрыве несущего физического соединения (смена Wi-Fi ↔ LTE, временная потеря сигнала) клиент переподключается к той же ноде.
- Клиент передаёт команду `smResume` с `MigrationTicket`.
- Нода сверяет `StreamSecret`, `SendOffset` и `RecvOffset`, подтверждая продолжение потока (`smResumeOK`) без разрыва удалённого TCP-сокета.

### Level 2 — Node Restart Recovery (Экспериментально)
- При плановом или аварийном перезапуске узла локальный snapshot сессий сохраняет метаданные активных сокетов.
- После рестарта клиент повторно заявляет права на поток по тикету.

### Level 3 — Cross-Node State Handoff (Архитектурный стандарт)
- Нода A экспортирует ограниченный `MigrationTicket` с привязкой к федеративному ключу провайдера.
- Нода B верифицирует тикет и принимает входящий поток клиента.

### Level 4 — Remote TCP Continuity (Ограничение)
- Прозрачное сохранение открытого TCP-сокета в мировой интернет при физической смене серверов требует проксирования на уровне распределённого anycast/overlay шлюза. Без overlay-шлюза продолжение сокета между физически разными датацентрами невозможно на уровне стандартов TCP.
