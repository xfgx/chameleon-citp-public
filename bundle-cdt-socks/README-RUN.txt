Chameleon CDT — Windows VPN-клиент (SOCKS5-over-CDT)
====================================================

ЧТО ЭТО
  cdt-socks — VPN-клиент: выход в свободный интернет через зарубежную ноду по
  туннелю Chaos-Dispersed Transport. Поток растворяется в несвязуемые фрагменты
  (хаос-геометрия портов/размеров/тайминга), надёжность — retransmit+ACK,
  мультиплексирование множества соединений. НЕ нужен TUN/админ — это
  userspace SOCKS5-прокси.

ТОПОЛОГИЯ
  Windows-клиент (за цензурой) -> CDT-дисперсия -> нода за рубежом -> интернет

БЫСТРЫЙ ТЕСТ (нода УЖЕ поднята на RU-тестовом сервере с этим ключом cdt.key)
  1. Распакуй. Рядом: cdt-socks-windows-amd64.exe + cdt.key.
  2. Запусти (cmd/PowerShell):
       cdt-socks-windows-amd64.exe -keyfile cdt.key -peer 192.0.2.10 -socks 127.0.0.1:1080
  3. Укажи SOCKS5-прокси 127.0.0.1:1080 в браузере/системе (с DNS через прокси).
  4. Открой сайт — трафик идёт диспергированным туннелем и выходит с IP ноды.

PRODUCTION (зарубежная нода — НЕ RU)
  0. Ключ (один раз, общий):  cdt-socks -genkey -keyfile cdt.key
     Положи ТОТ ЖЕ cdt.key и на зарубежную ноду, и на Windows-клиент.
  1. Зарубежный сервер (Linux): ./cdt-socks -node -keyfile cdt.key -c2nbase 20000 -c2ncount 48 -n2cport 23500
     (открой UDP 20000-20047 в файрволе ноды)
  2. Windows: cdt-socks-windows-amd64.exe -keyfile cdt.key -peer <IP_ЗАРУБЕЖНОЙ_НОДЫ> -socks 127.0.0.1:1080

ЗАМЕТКИ
  - При рестарте клиента подожди ~5-8с на пересинхронизацию (сессия+ротация эпох), дальше само.
  - Это SOCKS5 (TCP): браузеры/видео по HTTP/HTTPS идут. Для чистоты режь QUIC (UDP/443) в браузере.
  - Ключ cdt.key — секрет; для продакшена сгенерируй свой (-genkey), не используй тестовый.
