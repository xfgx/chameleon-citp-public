Chameleon VPN — клиент для Windows 11
======================================

Состав комплекта:
  chamd.exe          — клиентский демон (свежая сборка: слои 6-8 + обвязка
                       автопилота: θ-геномы от борда, экзогенная сенсорика)
  wintun.dll         — драйвер TUN-адаптера (должен лежать рядом с chamd.exe
                       для режима полного VPN)
  data\servers.json  — конфигурация ноды (адрес, параметры Control Fabric)
  data\client.key    — персональный ключ этого устройства (в белом списке ноды)

ВАЖНО: data\servers.json и data\client.key — чувствительные файлы.
client.key — это идентичность устройства в allowlist ноды. Не передавайте
комплект третьим лицам.

Запуск:
  1. Распаковать комплект в один каталог (структуру data\ сохранить).
  2. Полный VPN (автоподхват всего TCP): запустить ОТ АДМИНИСТРАТОРА:
       chamd.exe -tun
     Без прав администратора: просто
       chamd.exe
     — поднимется системный прокси Windows на SOCKS5 127.0.0.1:1080.
  3. Панель управления и журнал: http://127.0.0.1:8080

Полезные флаги:
  -flavor auto       — маска ритма (по умолчанию auto; при RST/SNI-
                       интерференции автопилот применяет одноразовый θ-геном
                       от борда — слой 8; без θ — legacy-ротация flavor)
  -exo=false         — отключить пулл публичных измерений OONI в
                       data\netprofile.jsonl (слой 7; по умолчанию включён)
  -autopilot=false   — выключить автопилот целиком
  -cbr 40ms          — интервал CBR-паддинга (0 = выкл)
