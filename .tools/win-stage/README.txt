CDT / ChaosSync — Windows-клиент (сборка 2026-09-01, собрана на RU-ноде, Go 1.26.3)
====================================================================================

СОСТАВ
  cdt-socks-windows-amd64.exe        — VPN-клиент: SOCKS5-прокси поверх CDT
                                       (дисперсия геометрии + AEAD + ротация эпох + CST).
                                       Без прав администратора, без TUN.
  cdt-probe-windows-amd64.exe        — диагностический пробник CDT.
  chaossync-client-windows-amd64.exe — клиент хаос-синхронизации (control-plane,
                                       канал доказательства; медленный по построению).
  chaossync-selftest-windows-amd64.exe — самотест детерминизма хаос-ядра.
  data\cdt.key                       — общий мастер-ключ CDT (СЕКРЕТ, не публиковать).
  data\chaossync.key                 — общий мастер-ключ chaossync (СЕКРЕТ).
  client.conf                        — параметры chaossync-клиента под живую ноду.
  run-cdt-socks.bat                  — запуск VPN-клиента.
  run-chaossync.bat                  — запуск chaossync-клиента (sync + кадр + эхо).
  SHA256SUMS                         — контрольные суммы (Get-FileHash -Algorithm SHA256).

БЫСТРЫЙ СТАРТ (VPN через SOCKS5)
  1. Запусти run-cdt-socks.bat  (это же вручную:
     cdt-socks-windows-amd64.exe -peer 192.0.2.10 -keyfile data\cdt.key)
  2. Укажи в браузере/системе SOCKS5-прокси: 127.0.0.1:1080
  3. Необязательно: флаг -geomauto включает автопилот дисперсии —
     автоподбор класса скрытности по риску с переключением на границах эпох.
  Примечание по NAT: клиент шлёт с фиксированного src-порта, нода отвечает в
  NAT-дыру (порт приёма 23500/udp). За очень жёстким NAT может понадобиться
  проброс UDP 23500 на этот ПК.

САМОТЕСТ ХАОС-ЯДРА (проверка bare-metal Windows — финальный шаг DoD)
  chaossync-selftest-windows-amd64.exe
  Должен напечатать золотой хэш:
  29f2315f353442c2bdd8183ad6d175dcd749929d4b095a6ab4cb6461d2ac5557
  Совпадение = динамика побитово та же, что на Linux-ноде (гейт Э1).

CHAOSSYNC-КЛИЕНТ (канал доказательства, НЕ для трафика)
  run-chaossync.bat (параметры в client.conf: нода 192.0.2.10:4500,
  T=8 c=0.85 rate=1000 S=32 batch=4, dur=60s, отправляет кадр-пробу).
  Ожидай: захват синхронизма за секунды; кадр ~20 байт идёт ~20 секунд в одну
  сторону — это честный предел физики синхронизации, а не неисправность.
  За 60 секунд прогон пересекает несколько ротаций эпох (resyncs=0 — норма).

ВАЖНО
  - Сборка включает CST (явная идентичность туннеля): со сборками CDT до
    2026-09-01 НЕ совместима. Нода уже обновлена до этой сборки.
  - TUN/Wintun-режим (полный VPN всего трафика без прокси) — следующий этап,
    в этот комплект не входит (нужен Wintun и права администратора).
  - Ключи в data\ — секреты. Архив не пересылать по открытым каналам.
