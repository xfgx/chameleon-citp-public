# КЛАССИФИКАЦИЯ НАШЕЙ РАЗРАБОТКИ (кратко)

Общее: семейство протоколов и транспорт для связи, устойчивой к DPI-классификации и блокировкам. Ниже — компоненты снизу вверх. Все «заявленные свойства» НЕ подтверждены независимым аудитом.

1. KS — ядро VPN (главный компонент).
   - Транспорт: UDP, порт по умолчанию 51820; интерфейс TUN «ks0».
   - Формат провода: nonce(12 байт) ‖ ciphertext; AEAD-Seal добавляет +28 байт; окно антиповтора 8192.
   - Ключевое расписание синхронизируется через ChaosSync (хаотическая синхронизация «ведущий/ведомый»); замысел — общая энтропия/ключи без явного согласования по проводу.
   - Заявлено (требует проверки): неклассифицируемость и несвязываемость потоков «by construction».

2. ChaosSync — слой хаотической синхронизации.
   - Несущая M8: датаграмма [1 байт счётчик][8 байт сэмплов]; кодирование типа CSK (chaos shift keying).
   - Идея: приёмник восстанавливает состояние хаотической системы отправителя; качество синхронизации по метрике NMSE (порог успеха в наших доках NMSE<0.1).

3. CDT — «хаотический» транспорт датаграмм.
   - Порт-хоппинг: блок из 48 портов от base=20000; отдельный probe-сокет ~23500.
   - Gap-тайминг: межпакетные интервалы (g.GapUs) как канал/маскировка формы трафика.
   - Мультиплекс потоков: streamID(4, BE) ‖ type(1) ‖ len(2, BE) ‖ payload; типы 0–4.

4. Chameleon (cham-server / chamd / cham-client) — фронтинг и управляющая ткань.
   - TTLS-фронт: кадр "TTLS"(4) ‖ seq(8) ‖ nonce(12) ‖ AES-GCM ct/tag; порт TTLS 55353.
   - Control fabric поверх HTTPS (порты 9443/9444/9445, WS 9446); DNS-биндинг (5353, план UDP/53).

5. CITP — протокол объектного уровня (формат PDU, мультиплекс команд 0x01–0x0F, миграция сессий).

# ЗАДАЧА ДЛЯ ТЕБЯ
1. Опираясь на этот стек (особенно KS и ChaosSync), предложи ИННОВАЦИОННЫЕ идеи противодействия ТСПУ и DPI.
2. Ищи то, что, насколько тебе известно, ещё никем не описано и не реализовано.
3. Для КАЖДОЙ идеи ОБЯЗАТЕЛЬНО проверь, существует ли уже такой приём (prior art), и присвой метку новизны с ближайшим аналогом.
4. Не выдавай желаемое за факт: помечай гипотезы и указывай минимальный эксперимент для проверки.
